## Eidolon Objective-C CocoaPods

artsy/eidolon `44486ed9149f16b3eb3a5e687f99ae078309f4fe` Podfile.lock versions, fetched as the GitHub
archive of each resolved commit and vendored byte-identical (only the files each locked podspec
selects, its resources, licence and podspec). Per-file SHA-256 values and archive checksums are in
`Sources/EidolonPods/PROVENANCE.json`; the SwiftPM package around them is generated by
`Tools/ingest/objc_pods_package.py` (`Sources/EidolonPods/README.md`).
