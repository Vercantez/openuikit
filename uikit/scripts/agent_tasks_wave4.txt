conformance-harness|cursor-grok-4.6-high|Build the conformance-app harness described in docs/HILLCLIMB.md, with the first app. (1) `Sources/ConformanceApps/NavFlow/` — a small UIKit-only app written the way real apps are (a UINavigationController with prefersLargeTitles, a root UITableViewController of grouped rows with disclosure indicators built from a data source, a detail UIViewController with Auto Layout labels and a UISwitch bound to UserDefaults, a modal sheet from a bar button; no imports beyond UIKit/Foundation). It exposes `enum NavFlowApp { static func makeRoot() -> UIViewController; static func perform(_ action: String) }` where actions are named steps ("push", "toggle", "present", "dismiss", "pop", "back-swipe" if feasible) so the SAME source drives both sides without synthesised touches. (2) `Sources/ConformanceApps/NavFlow/script.json`: a timeline of `{t, action}` and `captures: [t...]`, like scripts/nav_push_large.json. (4) openhost `--app NavFlow --script ... --record ...` boots the same source through Sources/openhost/AppMode.swift and records the same files at the same times at the same scale. (6) Run it, report the per-capture scores, and fix the two largest measured differences under the iOS cut. Keep the Catalyst gate green and the real-app screens at their floors.
