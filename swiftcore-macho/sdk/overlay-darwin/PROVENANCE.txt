overlay-darwin — Darwin Platform overlay headers missing from, or
incomplete in, machorun's clean-room SDK

These are Apple's published headers, copied verbatim. They are NOT
clean-room stand-ins. stage_overlay_darwin.sh copies them into
$W/sdk/MacOSX.sdk. math.h and MacTypes.h REPLACE machorun's category-(c)
stand-ins in the staged tree only — never in machorun/sdk/.

Enumerated from the operator Darwin.o log (overlays3.log), not by hand:
  sig_t          — already in machorun sys/signal.h (Libc/xnu); Darwin.modulemap
                   must export it
  FILE           — already in machorun _stdio.h; Darwin.modulemap must export it
  OSStatus       — CarbonHeaders MacTypes.h (replaces machorun's 201-line
                   clean-room MacTypes.h)
  extern_proc    — already in machorun sys/proc.h (xnu); Darwin.modulemap
  MAP_FAILED     — already in machorun sys/mman.h; Darwin.modulemap
  acosf/acosl…   — Libm Intel math.h (explicit f/l prototypes, not macros)

When scratch/sysroot_fe4-x86_64 exists (operator phase-2 FE sysroot),
stage_overlay_darwin.sh copies Apple's SDK headers + the generated Darwin
family modulemaps from THAT tree instead of (or on top of) these pins.
The FE sysroot is where FoundationEssentials already builds for x86.

Do not hand-write prototypes. Darwin.modulemap names only headers the
sysroot actually stages.
