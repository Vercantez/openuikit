# The Objective-C methods CoreFoundation messages
#
# 151 distinct selectors across 24 Foundation classes, harvested by RESTORING
# CF's ObjC dispatch macros and compiling: each one is a clang
# "instance method '-x' not found" against forward-declared classes.
#
# Provenance: foundation-macho scripts/patch_cf_objc.py applied to
# swift-corelibs-foundation release/6.2, compiled -x objective-c
# -DINCLUDE_OBJC=1 -DDEPLOYMENT_RUNTIME_SWIFT=0, arm64-apple-macos13.0.
#
# WHY THIS LIST EXISTS: with only @class forward declarations the messages
# compile anyway, with "return type defaults to 'id'" -- clang GUESSING the
# signature. That is the same silent-miscompilation shape as an implicit
# function declaration, so these need real @interface declarations, not
# forward declarations.
#
# This is the size of the Foundation header CF must see at compile time.
# It overlaps heavily with the 128 selectors libswiftCore needs (docs/
# DECISION.md §1.3) -- -length, -characterAtIndex:, -count, -objectForKey:,
# -getCharacters:range:, -_cfTypeID -- so one set of NS* implementations
# satisfies both consumers.
#
